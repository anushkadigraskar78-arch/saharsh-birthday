# Saharsh Birthday Surprise 💗

This is a Vite + React birthday website made from the uploaded memories.

## Run it

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Open the terminal in this folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite.

## Your photos

The 11 uploaded photos are already inside:

`public/photos/`

They are named `memory1.jpeg` through `memory11.jpeg`.

## Music

Three original soft instrumental WAV tracks are included so the website works immediately.

If you want real songs instead, replace:
- `public/songs/01-slow-birthday.wav`
- `public/songs/02-warm-memory.wav`
- `public/songs/03-happy-vibes.wav`

with your own audio files and update the filenames in `src/App.jsx`.

## Video

The uploaded WhatsApp video is included at:

`public/video/memory-video.mp4`

It is kept ready for an optional video section. The current flow focuses on the photos + interactive surprise.

## Easy edits

All main birthday text is in `src/App.jsx`.

Change:
- `Saharsh`
- the 3 bouquet names
- song names
- balloon messages
- final letter

No extra packages are required.
